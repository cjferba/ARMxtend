# Citing armxtend


If you use armxtend as part of your workflow in a scientific publication, please consider citing the armxtend repository with the following DOI:

###Streaming module: 

Fernandez-Basso, C., Francisco-Agra, A. J., Martin-Bautista, M. J., & Ruiz, M. D. (2019). [Finding tendencies in streaming data using big data frequent itemset mining](http://cjferba.github.io/armxtend/) Knowledge-Based Systems, 163, 666-674..
```
@article{fernandez2019finding,
  title={Finding tendencies in streaming data using big data frequent itemset mining},
  author={Fernandez-Basso, Carlos and Francisco-Agra, Abel J and Martin-Bautista, Maria J and Ruiz, M Dolores},
  journal={Knowledge-Based Systems},
  volume={163},
  pages={666--674},
  year={2019},
  publisher={Elsevier}
}
```
[![DOI](https://img.shields.io/badge/KNOSYS-2018.09.026-green)](https://doi.org/10.1016/j.knosys.2018.09.026)


###Fuzzification module: 

Fernandez-Basso, C., Ruiz, M. D., & Martin-Bautista, M. J.  (2020). [A fuzzy mining approach for energy efficiency in a Big Data framework](http://cjferba.github.io/armxtend/) IEEE Transactions on Fuzzy Systems.
